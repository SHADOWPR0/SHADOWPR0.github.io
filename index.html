Personal Query Link

A personal connection between Grok and Google BigQuery, configured and operated by its account owner.

What it does

This OAuth configuration lets John authorize Grok's Google Cloud BigQuery connector to use Google's BigQuery MCP service. It supports exploring dataset and table metadata, running SQL queries, and retrieving query results within the permissions of the connected Google account.

The requested BigQuery permission includes viewing and managing BigQuery data and jobs. It is broader than read-only access. Queries may incur charges from Google Cloud. The OAuth client does not create new Google Cloud IAM privileges.

Who it is for

This is a personal-use integration for its account owner, not a public application or a service offered to other users. There is no public registration on this website. Google, BigQuery, Grok, and their respective providers are independent services; this configuration is not endorsed by or operated by Google or Grok's provider.

How information moves

Google handles sign-in and consent. Grok receives the authorization needed to call BigQuery and may process queries, returned data, and generated responses. This information site is static: it has no sign-in form, query interface, application database, or embedded analytics.

Read the privacy notice for access, use, storage, sharing, and revocation details, and the use and support information for operational limits.
